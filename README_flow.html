MiM Proxy — Scan & Rewrite Loop

A transparent HTTP proxy that intercepts coding-agent requests, scans generated code for reciprocal/copyleft license matches, and re-prompts the LLM until the response is clean.
Client
Coding Agent
  • e.g. Claude Code, Cursor, cURL
  • LLM endpoint pointed at proxy
  • OpenAI or Anthropic chat API
Man-in-the-Middle
mim_proxy.py
  • Extracts prompt · forwards to LLM · inspects reply
  • Passes non-prompt traffic through untouched
Per response
  • Pull code from fenced blocks (or whole reply)
  • Send each snippet to Black Duck SCA
  • On reciprocal hits → build rewrite prompt & retry
  • Return clean response or give-up notice
Upstream
LLM Gateway
  • LiteLLM / MCP gateway
  • Generates code for the prompt
  • Re-invoked on each rewrite pass
License Scanner
Black Duck SCA
  • Called via run_snippet_hash.sh at BLACKDUCK_HOST
  • Hashes snippet → matches against KnowledgeBase
  • Returns snippetMatches grouped by license category (RECIPROCAL, PERMISSIVE, …)
  • Proxy triggers only on RECIPROCAL / WEAK_RECIPROCAL
Env: BLACKDUCK_MCP_GATEWAY_URL · BEARER_TOK · BLACKDUCK_HOST
Observability: /health · /traces
